# Proving Grounds for Meitou

roscatoday's C# port of Shutori's RE_Kenshi plugin Proving Grounds (workshop 3774745195), shipped with the game by the author's leave
([ports](../../docs/formats/rekenshi.md#ports)). Source: https://github.com/roscatoday/ProvingGroundsMeitou at `cc13544` (0.2.0), its
`ProvingGrounds/Core` and `ProvingGrounds/src` copied unchanged into one project; its tests, golden data, the original C++ and its
development docs stay in that repository. GPLv3: `LICENSE`, `NOTICE.md`. To sync a new version, copy those two folders again.
